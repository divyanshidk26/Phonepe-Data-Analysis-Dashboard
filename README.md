# 📊 PhonePe Data Analysis Dashboard

An interactive and executive-ready *Power BI Dashboard* designed to analyze transaction trends, user demographics, and key performance metrics for PhonePe.

---

## 🌟 Overview & Transformation

This project involved transforming a basic data view into a modern, cohesive, dark-themed analytical dashboard optimized for user readability and data-driven insights.

### Key Improvements Made
* *UI/UX Optimization:* Implemented a modern dark-slate color palette (#1E222A / #272C36) with subtle visual containers and consistent border radiuses.
* *KPI Formatting:* Redesigned key performance indicators (KPIs) with structured visual hierarchies and custom callout metrics.
* *Data Clarity:* Enhanced chart visual contrast, added clear data labeling, and optimized legend layouts to prevent visual clutter.
* *Interactive Elements:* Added dynamic slicers for monthly filtering and interactive tooltips across all time-series and demographic visualizations.

---

## 📈 Dashboard Features & Insights

* *Top KPIs:* Real-time visibility into Total Transaction Value ($3.47bn), Total Transactions (300K), Success Rate (96.00%), and Total Users (108K).
* *MoM Metrics:* Dedicated KPI cards tracking Month-over-Month (MoM%) growth percentages.
* *Monthly Trends:* Line chart visualizing volume and value trends across months.
* *Service Breakdown:* Bar visual displaying transaction values across various service categories (Loans, Insurance, Money Transfer, Recharge Bills).
* *User Demographics:* Donut chart breakdown analyzing user engagement across generational age segments (Gen X, Gen Z, Millennials, Boomers).
* *Usage Patterns:* Comparative analysis of Weekday vs. Weekend transaction distribution.

---

## 🛠️ Tech Stack & Skills Demonstrated

* *Tool:* Microsoft Power BI Desktop
* *Data Modeling:* DAX (Data Analysis Expressions) for MoM% calculations, dynamic measures, and KPI metrics.
* *UI/UX Design:* Custom visual containers, accessibility color palette, grid alignment, and typography hierarchy.
